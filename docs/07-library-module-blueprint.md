> **الحالة:** مقترح للمراجعة · بلا كود · بتاريخ 2026-09-03
> **النطاق:** `/student/library` · `/student/subjects/{subject}/resources` · `/teacher/library`

---

## ملخّص تنفيذي — خمسة قرارات تحتاج موافقتك

| # | القرار | التوصية |
|---|---|---|
| ١ | **لا جدول جديد** | `library_files` موجود فعلاً بـ16 عموداً ويغطّي 80% من المطلوب. نُوسّعه ولا نُنشئ `libraries` أو `resources`. |
| ٢ | **controller التسليم أولاً** | لا يوجد اليوم أي مسار يخدم ملفاً. هذا يسبق كل شاشة — بدونه المكتبة واجهة بلا محتوى. |
| ٣ | **المعاينة عبر رابط موقّع** | المعاينة داخل المتصفّح لا تعني قرصاً عاماً. `<iframe>` يشير إلى مسارنا الموقّع، لا إلى الملف. |
| ٤ | **التصنيف عمود لا جدول** | أربع فئات ثابتة (ملخّصات · امتحانات · أوراق عمل · مراجعات) = enum، لا جدول تصنيفات. |
| ٥ | **الوحدة تُورَث من المحاضرة** | `lectures.unit_name` بُني للتوّ. ملف مربوط بمحاضرة يرث وحدتها؛ الملف الحرّ يحمل وحدته بنفسه. |

## ١ · ما هو قائم فعلاً (نتيجة الفحص)

### الجدول موجود — وهذا يغيّر المقترح

طلب البريف جدولاً باسم `libraries` أو `resources`. **الجدول قائم منذ المرحلة 4 باسم `library_files`:**

```
id · subject_id · lecture_id · teacher_id · title · original_filename
storage_path · mime_type · size_bytes · download_count · is_published
uploaded_by · timestamps · deleted_at · deleted_by
```

مقارنة بما اقترحه البريف:

| عمود مقترح | الحالة |
|---|---|
| `title` · `file_path` · `file_size` · `subject_id` · `download_count` · `is_published` | ✅ موجود (بأسماء `storage_path` و`size_bytes`) |
| `file_type` | ⚠️ موجود كـ`mime_type` — لكنه **ليس** الفئة التعليمية |
| `unit_name` | ❌ ناقص |
| التصنيف (ملخّص/امتحان/…) | ❌ ناقص |
| عدد الصفحات | ❌ ناقص |

> 🔴 **إنشاء جدول ثانٍ يعني جدولين لنفس الشيء.** الملفات ستنقسم بينهما، وشاشة الطالب ستضطر لقراءة الاثنين، وسلّة المحذوفات ستحتاج نوعين. التوصية: **توسيع `library_files` بثلاثة أعمدة.**

### ثلاث حقائق أخرى من الفحص

1. **`lecture_id` موجود بالفعل** — الربط بمحاضرة بعينها مبنيّ، ولم يُستعمل بعد.
2. **`storage_path` في `$hidden`** — محجوب عن أي تسلسل عمداً؛ تسريب المسار يكشف بنية القرص.
3. **`download_count` يُدار بـ`increment()`** — معلَن في النموذج، ولا يُسنَد من الطلب.

### 🔴 الثغرة الكبرى: لا يوجد مسار تسليم

لا `LibraryFileController` ولا أي مسار يخدم ملفاً. اليوم:

- العمود موجود ✅
- القرص الخاص مُهيّأ (`storage/app/private`) ✅
- **الملف لا يمكن تنزيله بأي طريقة** ❌

أي شاشة مكتبة تُبنى قبل هذا المسار هي واجهة تعرض ملفات لا يستطيع أحد فتحها.

## ٢ · المقارنة المرجعية

> ملاحظة أمانة: هذا استخلاص لأنماط شائعة في هذه المنصّات، لا فحصاً حيّاً لواجهاتها اليوم.

### أ) كيف تُصنَّف الملفات؟

| المنصّة | النمط | ما يعنينا |
|---|---|---|
| **Udemy** | الموارد **ملحقة بالدرس** حصراً — لا مكتبة مستقلّة | بسيط، لكنه يجعل «كل امتحانات المادة» غير قابلة للتجميع |
| **Coursera** | القراءات **عناصر في الوحدة**، بنفس مرتبة الفيديو | الوحدة هي وحدة التنظيم لا المادة |
| **Scribd** | مكتبة مسطّحة + بحث قوي + وسوم | يصلح لمحتوى عام لا لمنهج |
| **بوابات أكاديمية** | مزدوج: مرفقات المقرر + أرشيف امتحانات سابقة منفصل | **الأقرب لحالتنا** |

**الاستنتاج:** طالب التوجيهي يسأل سؤالين مختلفين:

- «ما ملفات هذه المحاضرة؟» → سياق المحاضرة
- «أين كل امتحانات الرياضيات السابقة؟» → سياق الأرشيف

نمط واحد لا يخدم السؤالين. لذلك: **ملف واحد، مدخلان.**

### ب) البيانات الوصفية الأساسية

مرتّبة بحسب ما يقرّر فعلاً:

| البيان | الأولوية | لماذا |
|---|---|---|
| النوع (PDF/Word/ZIP) | 🔴 عالية | يقرّر إن كان الملف يُعايَن أصلاً |
| الفئة التعليمية | 🔴 عالية | «امتحان» و«ملخّص» نيّتان مختلفتان تماماً |
| المادة + الوحدة | 🔴 عالية | مسار الوصول الوحيد للطالب |
| الحجم | 🟡 متوسطة | حرج على بيانات الجوال في فلسطين |
| عدد الصفحات | 🟡 متوسطة | «12 صفحة» يقرّر أكثر من «2.4 ميغابايت» |
| تاريخ النشر | 🟡 متوسطة | «امتحان 2024» مقابل «2019» فرق جوهري |
| عدد التنزيلات | 🟢 منخفضة | إشارة اجتماعية، ليست قراراً |

### ج) البحث والتصفية

النمط السائد: **تصفية بواجهة، لا بحث نصّي حرّ**، لأن الطالب لا يعرف اسم الملف — يعرف مادته ووحدته ونوع ما يريد.

الترتيب المعتمد عالمياً: `المادة ← الوحدة ← الفئة ← بحث نصّي (أخيراً)`.

### د) المعاينة مقابل التنزيل

- **Scribd/Coursera:** معاينة داخل الصفحة أولاً، والتنزيل فعل ثانوي.
- **Udemy:** تنزيل مباشر فقط.

**لحالتنا:** المعاينة أهمّ، لسببين — بيانات الجوال، والمحتوى المدفوع (ملف نُزّل هو ملف خرج عن سيطرتنا).

## ٣ · تجربة الطالب

### أ) `/student/library` — لوحة المكتبة

```
┌─────────────────────────────────────────────┐
│  مكتبة موادي                                │
│  كل الملخّصات والامتحانات وأوراق العمل      │
├─────────────────────────────────────────────┤
│  🔍 [ ابحث في ملفاتك…                    ]  │
├─────────────────────────────────────────────┤
│  [الكل] [ملخّصات] [امتحانات] [أوراق] [مراجعات] │
├─────────────────────────────────────────────┤
│  المادة: [كل موادي ▾]   الوحدة: [كل ▾]      │
├─────────────────────────────────────────────┤
│  ┌────────┐ ┌────────┐ ┌────────┐          │
│  │ بطاقة  │ │ بطاقة  │ │ بطاقة  │          │
│  └────────┘ └────────┘ └────────┘          │
└─────────────────────────────────────────────┘
```

**قرارات التصميم:**

| القرار | السبب |
|---|---|
| الفئات **أزرار لا قائمة** | أربع فئات فقط — القائمة المنسدلة تُخفيها خلف نقرة بلا داعٍ |
| فلتر الوحدة **يعتمد على المادة** | «الوحدة الأولى» في الرياضيات غيرها في الفيزياء؛ الفلتر يُعاد بناؤه عند تغيير المادة |
| البحث **أخيراً** | الطالب يتصفّح أكثر مما يبحث |
| نطاق المكتبة = **مواد فرعه** | مبدأ الإقصاء المخصّص — لا يرى الطالب ملفات فرع آخر |

**الحالة الفارغة** تسمّي سببها: «لا ملفات في هذه الوحدة بعد» ≠ «لا ملفات في مادتك» ≠ «لا نتائج لبحثك».

### ب) بطاقة المورد

```
┌──────────────────────────────┐
│  📄 PDF          [امتحان]    │
│                              │
│  امتحان الفصل الأول 2025     │
│                              │
│  الرياضيات · الوحدة الثانية   │
│  12 صفحة · 2.4 م.ب           │
│  نُشر: 2026-08-14            │
├──────────────────────────────┤
│  [ معاينة ]      [ تحميل ]   │
└──────────────────────────────┘
```

**تفاصيل حاكمة:**

- 🔴 **«معاينة» أساسي و«تحميل» ثانوي.** التنزيل يخرج الملف عن سيطرتنا نهائياً؛ التسلسل البصري يجب أن يعكس ذلك.
- ⚠️ **«معاينة» تختفي لغير القابل للمعاينة** (Word · ZIP). زرّ لا يعمل أسوأ من غيابه.
- الحجم دائماً ظاهر — قرار حقيقي على بيانات الجوال.
- «12 صفحة» يُعرض حين نعرفه فقط، ولا يُخترع.
- شارة الفئة بلون ثابت لكل فئة (الامتحان ≠ الملخّص بصرياً).

### ج) `/student/subjects/{subject}/resources` — ملفات المادة

نفس البطاقة، بلا فلتر المادة (معروفة من السياق)، **مجمَّعة بالوحدة** بنفس أكورديون شاشة المشاهدة — اتساق مع ما بُني للتوّ.

### د) عارض الملفات داخل المنصّة

| البند | القرار |
|---|---|
| الشكل | Lightbox يغطّي الشاشة، خلفية معتمة، إغلاق بـEsc وبالنقر خارجه |
| المحرّك | `<iframe>` على **مسارنا الموقّع** — لا مسار ملف، ولا مكتبة PDF خارجية في المرحلة الأولى |
| الترويسة | اسم الملف · المادة · زرّ تنزيل · زرّ إغلاق |
| الحالة | لا يغيّر الرابط ولا يُعيد تحميل الصفحة — الطالب يعود لموضعه بالضبط |
| الاحتياط | فشل التضمين يعرض «تعذّر العرض — حمّل الملف» لا إطاراً أبيض |

> ⚠️ **قيد معروف:** بعض متصفّحات الجوال لا تعرض PDF داخل `iframe` وتفرض التنزيل. الحلّ في المرحلة الأولى: كشف ذلك وعرض زرّ التنزيل مباشرة، لا إخفاء الفشل.

## ٤ · تجربة المعلّم — `/teacher/library`

### أ) نافذة الرفع

| الحقل | النوع | ملاحظات |
|---|---|---|
| منطقة السحب والإفلات | ملف واحد | `x-ui.file-dropzone` **موجود في المشروع** ويُعاد استعماله |
| العنوان | نصّ · إجباري | يُقترح تلقائياً من اسم الملف، وقابل للتعديل |
| المادة | قائمة · إجباري | **مواد المعلّم المسندة حصراً** — نفس قاعدة شاشة المحاضرات |
| الوحدة | نصّ + اقتراحات | يقرأ `lectures.unit_name` القائمة — نفس نمط حقل المحاضرة |
| ربط بمحاضرة | قائمة · اختياري | يستعمل `lecture_id` القائم؛ اختياره يرث وحدتها |
| الفئة | أزرار · إجباري | أربع فئات ثابتة |
| الحالة | مسودّة / منشور | نفس نمط المحاضرات |

**قواعد التحقّق المقترحة:**

- الصيغ: `pdf, doc, docx, ppt, pptx, zip`
- الحجم الأقصى: **20 ميغابايت** (اقتراح — يحتاج قرارك)
- ⚠️ الفحص على **الخادم** لا على الواجهة فقط؛ سحب وإفلات ادّعاء عميل.

### ب) جدول الإدارة

| العمود | المحتوى |
|---|---|
| الملف | أيقونة النوع + العنوان + اسم الملف الأصلي |
| المادة / الوحدة | شارتان |
| الفئة | شارة ملوّنة |
| الحجم | مُنسَّق |
| التنزيلات | عدّاد |
| الحالة | منشور / مسودّة |
| إجراءات | معاينة · تعديل · حذف (بـSweetAlert2 القائم) |

**النطاق:** يرى المعلّم ملفات **مواده المسندة** — بما فيها ما رفعه زميل سبقه، تماماً كالمحاضرات. الفلترة على المادة لا على `uploaded_by`.

## ٥ · نموذج البيانات المقترح

### التوصية: توسيع `library_files` — لا جدول جديد

| العمود الجديد | النوع | ملاحظات |
|---|---|---|
| `category` | `string(20)` | enum تطبيقي: `summary` · `exam` · `worksheet` · `revision` |
| `unit_name` | `string(160)` nullable | نصّ حرّ، **نفس اصطلاح `lectures.unit_name`** |
| `page_count` | `unsignedSmallInteger` nullable | يُملأ للـPDF فقط حين يُستخرج |
| `published_at` | `timestamp` nullable | تاريخ النشر ≠ تاريخ الرفع؛ «امتحان 2024» يحتاج تاريخه |

**فهارس مقترحة:** `[subject_id, category]` · `[subject_id, unit_name]` · `deleted_at` (لا يُنشئه `softDeletes()` تلقائياً).

### استراتيجية الوحدة

```
ملف مربوط بمحاضرة  →  يرث unit_name من المحاضرة
ملف حرّ على المادة  →  يحمل unit_name الخاص به
ملف بلا وحدة       →  يقع في مجموعة «ملفات المادة» الافتراضية
```

> ⚠️ **الوراثة تُحسب عند العرض لا تُخزَّن.** نسخ الوحدة إلى الملف يعني قيمتين تنحرفان حين يعدّل المعلّم وحدة المحاضرة.

### ما لا نضيفه ولماذا

| مقترح | القرار |
|---|---|
| جدول `categories` | ❌ أربع فئات ثابتة لا تبرّر جدولاً وشاشة إدارة |
| جدول `units` | ❌ نصّ حرّ متّسق مع ما بُني للمحاضرات |
| `file_type` منفصل | ❌ `mime_type` موجود؛ الأيقونة تُشتق منه |
| علاقة morph إلى `media` | 🔴 **ممنوع بنيوياً** — `media` للأصول التسويقية العامة، وملف المكتبة محتوى مدفوع على قرص خاص |

## ٦ · الأمن والتسليم — أخطر بند

### المسار المقترح

```
الطالب يضغط «معاينة»
      ↓
GET /library/{file}/preview   ← مسار موقّع قصير العمر
      ↓
Controller يفحص: الفرع ✓ · النشر ✓ · (الاشتراك لاحقاً)
      ↓
response()->file() من القرص الخاص
Content-Disposition: inline        ← معاينة
Content-Disposition: attachment    ← تنزيل
```

### قواعد غير قابلة للتفاوض

| القاعدة | السبب |
|---|---|
| 🔴 لا `Storage::url()` ولا مسار تحت `public/` | رابط مباشر = تسريب مجاني يهدم نموذج العمل |
| 🔴 الفحص في الـcontroller لا في الواجهة | إخفاء الزرّ ليس حراسة |
| ⚠️ الروابط الموقّعة **قصيرة العمر** (15 دقيقة مقترحة) | رابط دائم يُشارَك في مجموعة واتساب خلال ساعة |
| ⚠️ `download_count` يزيد على **التنزيل** لا المعاينة | خلطهما يجعل الرقم بلا معنى |
| ⚠️ `storage_path` يبقى في `$hidden` | لا يُسلسَل في أي استجابة |

> 🔴 **الحدّ الواقعي:** رابط موقّع يمنع الوصول غير المصرَّح، **ولا يمنع** طالباً مصرَّحاً من تنزيل الملف وإعادة نشره. هذا حدّ كل منصّة تعليمية، ويُدار بالعلامة المائية والقبول لا بالتقنية. يستحق قراراً منك: **هل نضيف علامة مائية باسم الطالب على PDF؟** (يرفع الكلفة التقنية كثيراً).

| الخطر | العلاج |
|---|---|
| N+1 على المادة والوحدة والمعلّم | تحميل مسبق معلَن في scope واحد — نفس نمط `Branch::withPublicContent()` |
