## 3 · صفحة المادة — ✅ مبنية
`/student/subjects/{id}` · `StudentShell` · فرعه + اشتراك ساري

**الهدف:** كل ما يخص المادة في مكان واحد — محاضراتها وملفاتها.

**البنية — نمط Hero + عمودان (مراجَع 2026-08-18، يُبطل نمط الأعمدة الثلاثة الأصلي أدناه):**

```
┌─────────────────────────────────────────────────────┐
│  Hero: أيقونة · اسم المادة · المعلم · شريط تقدّم ·   │
│        زر إجراء سريع (تابع/ابدأ)                     │
├───────────────────────────────┬─────────────────────┤
│  [محاضرات] [ملفات]            │  عن المادة (لاصقة)  │
│  ───────────────────────      │  المعلم              │
│  قائمة المحاضرات كاملة العرض   │  عدد المحاضرات       │
│  أو جدول الملفات               │  عدد الملفات         │
│                                │  [ابدأ]              │
│  عمود رئيسي (~70٪)             │  شريط جانبي (~30٪)   │
└───────────────────────────────┴─────────────────────┘
```

قرار: `grid-cols-[minmax(0,1fr)_340px]` بدل نسبة مئوية حرفية — عرض الشريط الجانبي ثابت (يناسب محتواه: صورة + نصوص + زر) ويعطي نسبة ~70/30 فعلية عند عروض سطح المكتب المعتادة دون أن يتمدّد الشريط بلا داعٍ على الشاشات الواسعة.

**ترتيب DOM = ترتيب RTL البصري مباشرة:** العمود الرئيسي أولاً (يظهر يميناً/البداية) ثم الشريط الجانبي (يسار/النهاية) — بلا حاجة لأصناف `order-*`. على الجوال: نفس الترتيب، تكديساً.

**عنصر المحاضرة الواحد:** رقم أو أيقونة تشغيل للمحاضرة الحالية · عنوان · مدة · شارة حالة (مكتملة/جارية/جديدة) · درجة الكويز إن وُجدت

**صف الملف الواحد:** أيقونة نوع · اسم · حجم · تاريخ · [تنزيل]

**المكوّنات المنتَجة:** `SubjectHero` · `Tabs` · `LectureListItem` · `FileRow` · `Breadcrumb` · `Pagination`

~~**أنماط Mintlify:** التخطيط ثلاثي الأعمدة~~ — أُبطل. الأعمدة الثلاثة (نمط مواقع التوثيق) استُبدلت بنمط منصّات LMS تجارية (Udemy/Coursera): Hero علوي + عمودان. السبب: النمط الثلاثي بدا مجزّأً وضيّقاً في المراجعة الفعلية؛ نمط الـHero أوضح تسلسلاً بصرياً لجمهور طلابي غير تقني. بقي من Mintlify: `segmented-tab` + `-active` · `property-row` · `badge-type`.

**على الجوال:** الشريط الجانبي (عن المادة) ينزل تحت العمود الرئيسي مباشرة — لا انطواء ولا درج منفصل؛ الـHero أعلى الصفحة يكفي لعرض المعلومات الحرجة (المعلم، التقدّم) قبل الوصول له.

> ⛔ **نقطة توقّف إلزامية — ما زالت سارية.** لا ننتقل للموجة 2 قبل اعتماد الشاشات الثلاث بصيغتها الحالية. أي تعديل لاحق عليها يتسرّب إلى 45 شاشة.

## 4 · مشاهدة المحاضرة — وتشمل الكويز ونتيجته — ✅ مبنية
`/student/lectures/{id}` · `StudentShell` **بوضع تركيز**

> ⚠️ **معماريتها الفعلية تختلف عن التصميم الأصلي أدناه (مراجَع 2026-08-18):** الكويز (شاشة 5) ونتيجته (شاشة 6) لا يُنتقَل إليهما كصفحة مستقلة. الثلاثة **شاشة واحدة فعلياً** — انظر "البنية الفعلية" تحت. مساراهما المستقلان (`/quiz` و`/quiz/result`) بقيا موجودين كنسخة احتياطية بلا JS، ووصفهما الأصلي (البنية القديمة) محفوظ أسفل هذا القسم للمرجعية فقط.

**الهدف:** الطالب يشاهد بلا تشتيت، وعند الانتهاء **يُفتح الكويز تلقائياً** داخل نفس الشاشة، وعند إنهائه **تظهر النتيجة** داخل نفس الشاشة أيضاً — بلا أي تنقّل صفحة كامل.

**البنية الفعلية — نمط Sprints.ai (فيديو/كويز/نتيجة كأقسام متبادلة):**

```
┌──────────────────────────────────────┬─────────────────┐
│  مسار تنقّل                            │                 │
│  ┌──────────────────────────────────┐ │  محتوى المادة   │
│  │ data-lecture-view="video"        │ │  (لاصق)         │
│  │  المشغّل (dir=ltr) · عنوان ·      │ │                 │
│  │  وصف · تنقّل سابق/تالي            │ │  ModuleAccordion │
│  ├── أو (نفس المكان، JS يبدّل) ─────┤ │  → TopicAccordion│
│  │ data-lecture-view="quiz"         │ │  → 3×TopicItem   │
│  │  QuizRunner كامل                 │ │  (نص/فيديو/كويز) │
│  ├── أو ────────────────────────────┤ │                 │
│  │ data-lecture-view="result"       │ │  روابط المحاضرة  │
│  │  QuizResultCard كامل             │ │  الحالية تُعالَج │
│  └──────────────────────────────────┘ │  محلياً، البقية  │
│                                        │  تنتقل فعلياً    │
└──────────────────────────────────────┴─────────────────┘
```

**آلية التبديل:** دالة JS واحدة مشتركة `showLectureView(mode)` (في `resources/js/app.js`) تُظهر أحد الأقسام الثلاثة الشقيقة وتُخفي البقية. روابط الفيديو/الكويز الخاصة **بالمحاضرة الحالية فقط** في شريط `TopicAccordion` الجانبي تُعترَض (`preventDefault`) وتستدعي هذه الدالة بدل التنقّل — روابط أي محاضرة أخرى في الشريط تتنقّل فعلياً كالمعتاد.

**وضع التركيز:** الشريط الجانبي (شريط المادة الرئيسي، لا شريط المحتوى الملاصق) ينطوي تلقائياً عبر حدثي `lecture:play`/`focus-mode:enter` ويعود عبر `lecture:ended`/`focus-mode:exit` — مُطبَّق حالياً على سطح المكتب فقط (`@media min-width:1024px`).

**الحدث الحاكم:** انتهاء الفيديو (تجريبياً: زر "محاكاة انتهاء المحاضرة" بانتظار مزوّد فيديو حقيقي — م-5) → مودال «أحسنت! جاهز للاختبار؟» → قسم الكويز يظهر مكان الفيديو. **لا يوجد زر «ابدأ الاختبار» يدوي.**

**قسم الكويز (كان الشاشة 5):** سؤال واحد بالشاشة · 4 خيارات (`QuizOption`) بمساحة نقر كاملة العرض ≥56px · بلا مؤقّت تنازلي · حفظ تلقائي في `localStorage` (`quiz-demo-{lectureId}`) يقاوم انقطاع النت وإعادة تحميل الصفحة · `ConfirmDialog` قبل الإنهاء لو فيه أسئلة غير مجابة.

**قسم النتيجة (كان الشاشة 6):** «٨ من ١٠» + `ScoreRing` + رسالة مشجّعة حسب النسبة · ملخّص صحيحة/خاطئة/النسبة · `AnswerReviewRow` لكل سؤال (نصّه · إجابتك · **الإجابة الصحيحة بجانبها مباشرة**) · [المحاضرة التالية] · [إعادة المحاولة] (محدودة بمحاولتين، `localStorage` مفتاح `quiz-attempts-{lectureId}`) · [عودة للمادة].

> 🔴 **قاعدة إنسانية لا تزال سارية:** الأحمر **يوضّح ولا يوبّخ**. لا أيقونات ✗ عملاقة · لا اهتزاز · لا صوت. الصح بجانب الخطأ فوراً.

**المكوّنات:** `VideoPlayer` · `Breadcrumb` · `Modal` · `Button` · `QuizOption` · `ProgressBar` · `ConfirmDialog` · `QuizResultCard` · `ScoreRing` · `AnswerReviewRow` · `Alert` · `ModuleAccordion` · `TopicAccordion` · `TopicItem`

> 🔴 **الاتجاه:** المشغّل كاملاً LTR — شريط الزمن يمشي يساراً←يميناً في كل ثقافات العالم. عكسه خطأ استخدام لا تفضيل.

⏳ **معلّق على م-5** (مزوّد الفيديو يحدّد شكل المشغّل الحقيقي وموثوقية حدث الانتهاء — المُطبَّق الآن محاكاة عرض فقط) و**م-2** (عدد المحاولات وقفل المحاضرة التالية — المُطبَّق الآن توصية `docs/01` §7 غير المحسومة رسمياً: محاولتان، لا قفل)

**البنية:**
| # | القسم | المحتوى |
|---|---|---|

**المعادلات الرياضية:** `dir="ltr"` + `<bdi>` — حرج للفرع العلمي.
