# قواعد ثنائية اللغة والاتجاه — palEducation

> المنصة عربية RTL أساساً، إنجليزية LTR ثانوياً. خطأ واحد هنا يتسرّب إلى 48 شاشة.

---

## 1. القاعدة الحديدية

**لا يوجد `left` أو `right` في هذا المشروع.** لا في CSS، لا في أصناف Tailwind، لا في أسماء المتغيرات أو المكوّنات.

### جدول الاستبدال الكامل

| ❌ فيزيائي | ✅ منطقي | ملاحظة |
|---|---|---|
| `ml-*` | `ms-*` | margin-inline-start |
| `mr-*` | `me-*` | margin-inline-end |
| `pl-*` | `ps-*` | padding-inline-start |
| `pr-*` | `pe-*` | padding-inline-end |
| `text-left` | `text-start` | |
| `text-right` | `text-end` | |
| `border-l` | `border-s` | |
| `border-r` | `border-e` | |
| `rounded-l-*` | `rounded-s-*` | |
| `rounded-r-*` | `rounded-e-*` | |
| `rounded-tl-*` | `rounded-ss-*` | start-start |
| `rounded-tr-*` | `rounded-se-*` | start-end |
| `left-*` | `start-*` | |
| `right-*` | `end-*` | |
| `float-left` | `float-start` | |
| `float-right` | `float-end` | |
| `inset-l-*` | `inset-s-*` | |
| `scroll-ml-*` | `scroll-ms-*` | |
| `divide-x-reverse` | — | يُدار تلقائياً |

### في CSS الخام
```css
/* ❌ */  margin-left: 1rem;  padding-right: 2rem;  border-left: 1px;  left: 0;
/* ✅ */  margin-inline-start: 1rem;  padding-inline-end: 2rem;
         border-inline-start: 1px;  inset-inline-start: 0;
```

### Flexbox و Grid
`flex-row` و`grid` ينعكسان تلقائياً مع `dir`. **لا تستخدم `flex-row-reverse` لمعالجة الـ RTL** — هذا يكسر الاتجاه الإنجليزي.

## 2. ما لا ينعكس أبداً

هذه العناصر تبقى LTR في كل اللغات. عكسها خطأ استخدام لا تفضيل ذوق:

| العنصر | لماذا | التنفيذ |
|---|---|---|
| **مشغّل الفيديو** | شريط الزمن يمشي يساراً←يميناً عالمياً. عكسه يربك كل مستخدم | `dir="ltr"` على الحاوية |
| **الأرقام** | `12:45` · `95%` · `2026` | تلقائي عبر Unicode Bidi |
| **التواريخ والأوقات** | | تلقائي |
| **المعادلات الرياضية** | حرج لمواد الفرع العلمي | `dir="ltr"` + `<bdi>` |
| **الكود والرموز** | | `dir="ltr"` |
| **البريد الإلكتروني والروابط** | | `<bdi>` |
| **أيقونات التشغيل ▶ ⏸ 🔊** | رموز عالمية | لا انعكاس |
| **الشعار** | | لا انعكاس |

---

## 3. الأيقونات التي تحتاج انعكاساً

هذه **تحتاج** انعكاساً يدوياً لأن معناها اتجاهي:

`chevron-left/right` · `arrow-left/right` · `undo` / `redo` · `reply` · `indent` / `outdent` · `trending-up` · `logout` · `send`

```blade
<x-icon name="chevron-left" class="rtl:-scale-x-100" />
```

**لا تنعكس:** `chevron-up/down` · `plus` · `search` · `settings` · `bell` · `user` · `trash` · `check`.

---

## 4. النص المختلط — الفخّ الأخطر

شائع جداً في المحتوى العلمي:

```
حل معادلة x² + 5x = 0 بطريقة CAS
```

بدون معالجة، ينقلب ترتيب المقطع اللاتيني بصرياً. الحل:

```blade
حل معادلة <bdi dir="ltr">x² + 5x = 0</bdi> بطريقة <bdi>CAS</bdi>
```

**قاعدة:** أي مقطع لاتيني أو رقمي مضمّن داخل جملة عربية يُلَفّ بـ `<bdi>`.

هذا ينطبق تحديداً على: أسماء المواد الإنجليزية · المصطلحات العلمية · أسماء الملفات · الرموز الكيميائية · معادلات الرياضيات والفيزياء.

## 5. التنفيذ في Laravel

### القالب الأساسي
```blade
<!DOCTYPE html>
<html lang="{{ app()->getLocale() }}"
      dir="{{ in_array(app()->getLocale(), ['ar']) ? 'rtl' : 'ltr' }}">
```

### بنية الترجمة
```
lang/
├── ar/
│   ├── auth.php        # الدخول والتسجيل
│   ├── student.php     # منطقة الطالب
│   ├── teacher.php     # منطقة المعلم
│   ├── admin.php       # لوحة الأدمن
│   ├── quiz.php        # الكويز والنتائج
│   ├── subscription.php
│   └── validation.php
└── en/  (نفس البنية)
```

### قواعد الترجمة
- **لا نص مكتوب مباشرة في Blade.** كل نص عبر `__('student.my_subjects')`
- المفاتيح إنجليزية وصفية بـ snake_case
- **نطاق الترجمة:** واجهة النظام فقط. **محتوى المعلمين لا يُترجم** — عنوان المحاضرة يبقى بلغة كاتبه
- التعدّد عبر `trans_choice` — العربية لها 6 صيغ جمع، انتبه

### تبديل اللغة
- يُحفظ في `session` + عمود `locale` في جدول المستخدمين
- Middleware يضبط `App::setLocale()` من الجلسة
- مبدّل اللغة في الشريط العلوي لكل القشرات الأربع

## 6. الطباعة العربية

| القاعدة | القيمة | السبب |
|---|---|---|
| حجم النص الأدنى | **16px** | العربية تحتاج حجماً أكبر من اللاتينية لنفس الوضوح |
| ارتفاع السطر (نص) | **≥ 1.75** | امتدادات المحارف العربية تتصادم عند 1.5 |
| ارتفاع السطر (عناوين) | **≥ 1.3** | |
| `letter-spacing` | **0 دائماً** | التباعد **يكسر اتصال الحروف** ويجعل الكلمة غير مقروءة |
| `text-transform` | **none** | لا معنى لها بالعربية |
| عرض سطر القراءة | **≤ 68ch** | السطر الطويل يُفقد العين مكانها |
| الأرقام | **غربية 0-9** | الطالب يراها في كتبه وورقة الامتحان |
| الجداول والدرجات | `tabular-nums` | يمنع رقص الأرقام |

> ⚠️ `tracking-tight` و`tracking-wide` على نص عربي = **خطأ فادح**. راجع أي مكوّن منسوخ من مرجع لاتيني.

## 7. قائمة فحص قبل اعتماد أي مكوّن

- [ ] لا يحتوي أي صنف فيزيائي (`ml`/`mr`/`pl`/`pr`/`left`/`right`/`text-left`/`text-right`)
- [ ] اختُبر في `dir="rtl"` **و** `dir="ltr"`
- [ ] الأيقونات الاتجاهية تنعكس، وغير الاتجاهية لا تنعكس
- [ ] النص المختلط ملفوف بـ `<bdi>`
- [ ] لا نص مكتوب مباشرة — كله عبر `__()`
- [ ] لا `letter-spacing` على العربية
- [ ] ارتفاع السطر ≥1.75 للنص
- [ ] اختُبر في الوضعين الفاتح والداكن

## 8. أمر فحص سريع

للعثور على أي خرق للقاعدة الحديدية في ملفات Blade:

```bash
grep -rnE '\b(ml|mr|pl|pr)-[0-9]|text-(left|right)|border-[lr]\b|\b(left|right)-[0-9]' resources/views/
```

المخرجات المتوقعة: **لا شيء**. أي نتيجة = خرق يجب إصلاحه.
