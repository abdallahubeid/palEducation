# مجلد الصور

صور الموقع، مرتّبة حسب القسم الذي تظهر فيه.

> ℹ️ **الصور المستعملة فعلياً تعيش في `public/images/`** — راجع [public/images/README.md](../public/images/README.md). هذا المجلد مساحة تحضير للأصول قبل نقلها.

## البنية
```
images/
├── hero/       شرائح السلايدر الثلاث (نسبة 4:3)
├── about/      صورة قسم «من نحن» (نسبة 4:3)
├── teachers/   صور المعلّمين (مربّعة 1:1)
├── voices/     صور الطلبة في الشهادات (مربّعة 1:1)
└── textures/   ملمس الورق — يستعمله .hero-canvas في app.css
```

## كيفية الربط
كل خانة صورة في المشروع تقبل مسار صورة:

```blade
<x-ui.media-slot src="{{ asset('images/hero/slide-1.jpg') }}" alt="..." />
<x-domain.teacher-card photo="{{ asset('images/teachers/samer.jpg') }}" ... />
```

بدون `src` تُعرض خانة مصمّمة بديلة — لا صورة مكسورة.
