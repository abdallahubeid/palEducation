# مجلد الصور — المصدر

> 🔴 **هذا هو المصدر المُتتبَّع في git.** `public/images/` نسخة **مولَّدة** ومستثناة في `.gitignore`، يُنتجها `sync.sh`:
> ```bash
> ./images/sync.sh
> ```
> أي تعديل تكتبه في `public/images/` **سيضيع** عند أول مزامنة. اكتبه هنا.

## البنية

```
public/images/
├── hero/       شرائح السلايدر الثلاث (4:3) — الصفحة الرئيسية
├── about/      صورة قسم «من نحن» (4:3)
├── teachers/   صور المعلّمين على الرئيسية (1:1)
├── voices/     صور الطلبة في الشهادات (1:1)
├── textures/   ملمس الورق — يستعمله .hero-canvas في app.css
├── img/        ⬅ حزمة أصول أُضيفت 2026-08-22 (92 ملفاً)
└── img1/       ⬅ حزمة أصول أُضيفت 2026-08-22 (20 ملفاً)
```

## ما يُستعمل فعلياً من `img/` و`img1/`

| الملف | النسبة | أين يظهر |
|---|---|---|
| `img/blog/1.jpg` | 640×427 | خبر: تعديلات منهاج الرياضيات |
| `img/blog/2.jpg` | 640×427 | خبر: نمط أسئلة الإنجليزية |
| `img/blog/3.jpg` | 640×427 | خبر: خطة المراجعة |
| `img/blog/4.jpg` | 640×427 | خبر: مواعيد الامتحانات (الخبر الأبرز + غلاف التفاصيل) · بطاقة «أكمل من حيث توقفت» |
| `img/blog/5.jpg` | 640×427 | خبر: إطلاق المكتبة |
| `img/blog/6.jpg` | 640×427 | خبر: قلق الامتحان |
| `img1/header.jpg` | 1366×768 | خبر: فيديوهات المختبر |
| `img1/team-1..4.jpg` | 400×400 | أساتذة صفحة الفرع |

بقية ملفات الحزمتين (نحو 100 ملف) **غير مستعملة بعد** — متاحة للشاشات القادمة.

## قاعدتان لازمتان

1. **كل مسار يمرّ عبر `asset()`.** المسار النسبي (`images/…` بلا `/`) يُحَل نسبةً إلى مسار الصفحة، فينكسر داخل `/student/…` أو `/news/…`. وقع هذا فعلاً في بطاقة «أكمل من حيث توقفت» وأُصلح.
2. **خانة 16:9 تأخذ صورة أفقية.** `object-cover` يقصّ الصورة العمودية إلى شريحة ضيّقة. ملفات `img1/courses-*.jpg` عمودية (500×600) فاستُبدلت بأفقية.

## الربط

```blade
<x-ui.media-slot :src="asset('images/img/blog/4.jpg')" alt="وصف عربي" ratio="16/9" />
<x-domain.teacher-card :photo="asset('images/img1/team-1.jpg')" ... />
```

بدون `src` تُعرض خانة مصمّمة بديلة — لا صورة مكسورة.

## المواصفات

| القسم | النسبة | العرض المقترح |
|---|---|---|
| الهيرو · الأخبار · المحاضرات | 16:9 أو 4:3 | ≥1200px |
| المعلّمون · الطلبة | 1:1 | ≥600px |

> ⏳ **الصور الحالية كلها مخزون عام (stock)** وليست فلسطينية ولا خاصة بالمنصة — راجع الفجوة #2 في `DESIGN.md`.
